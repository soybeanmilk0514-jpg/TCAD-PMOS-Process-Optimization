# 프로젝트 범위와 PMOS 전환

2026년 4월 「반도체집적공정」 수업의 중간 프로젝트. 작성자: 주수빈.

제출 보고서는 선행 NMOS 실습(3~14쪽), PMOS 전환 및 조건 정의(15~18쪽), PMOS 조건 탐색(19~28쪽), 결과와 공정 시각화(29~33쪽)로 구성됩니다. 이 저장소의 핵심 결과는 PMOS 부분에 한정합니다. 별도의 High-k/HfO₂ 프로젝트 결과를 합치지 않았습니다.

## PMOS 전환

| 구성 | NMOS 예제 | PMOS 변경 |
|---|---|---|
| Body 도핑 | Boron | Phosphorus |
| LDD 주입 | Arsenic | BF₂ |
| S/D 주입 | Phosphorus | BF₂ |
| Gate sweep | 0 → +2.5 V | 0 → -2.5 V |

BF₂는 원소가 아니라 분자 이온 형태의 주입종입니다. 보고서의 ‘3족 원소 BF₂’라는 표현은 그대로 사용하지 않았습니다.

## 목표

보고서 18쪽: 구동 전류 > 1e-5 A/µm, Ioff < 1e-14 A/µm, SS < 100 mV/dec. PMOS의 음전류는 크기로 비교합니다.

구조 시각화, 공정 시뮬레이션, 소자 전기 특성 계산은 서로 다른 역할입니다. 보고서의 ‘SDevice로 구조 시각화’ 표기는 포트폴리오에서 도구별 기능의 증거로 단정하지 않고 ‘TDR 구조 확인’으로 정리했습니다.
