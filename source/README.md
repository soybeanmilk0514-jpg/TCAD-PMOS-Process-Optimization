# Source Code Scope

이 폴더에는 보고서에서 실제로 확인 가능한 Sentaurus TCAD source와 각 모듈의 공개 범위를 정리했습니다.

## Contents

- `sprocess/`
  - 실제 보고서에서 확인 가능한 implant / spacer / anneal command
- `sdevice/`
  - PMOS bias 조건과 공개 범위
- `svisual/`
  - 결과 지표와 extraction code 공개 범위

전체 mesh, physics, electrode, solve block을 포함하는 완전한 simulation deck은 보존되어 있지 않으므로 임의로 재구성하지 않았습니다.
