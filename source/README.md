# 코드 범위

`sprocess/implant-anneal-excerpt.cmd`는 보고서 28쪽 캡처에서 읽을 수 있는 명령을 발췌한 것입니다. 완전한 실행 파일이 아니며 재실행 검증을 하지 않았습니다. 원본 프로젝트에 있던 앞뒤 공정과 구조 저장 명령은 생략했습니다.

Workbench parameter: LDD_Dose=1e13, LDD_E=4, SD_Dose=7e15, SD_E=7, RTA=1. Lg=0.25.

RTA는 캡처에 표시된 원래 변수값을 보존했습니다. 주석으로 단위를 임의 보완하거나 실행 가능한 완성 코드로 확장하지 않았습니다.
