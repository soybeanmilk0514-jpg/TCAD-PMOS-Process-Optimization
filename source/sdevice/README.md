# SDevice Source Scope

원본 SDevice 입력 파일 전체는 현재 저장소에 포함되어 있지 않습니다.

보고서에서 확인 가능한 전기적 조건은 다음과 같습니다.

- PMOS gate sweep: 0 → -2.5 V
- 최종 결과 비교 drain bias: -0.05 V, -1.0 V
- on-current reference: Vg = -2.5 V
- off-current reference: Vg = 0 V

실제 electrode, physics, solve block과 sweep step은 원본 입력 파일 확인이 필요하므로 임의로 재구성하지 않았습니다.
