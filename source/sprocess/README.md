# SProcess Source Scope

## Included

- [implant-anneal-excerpt.cmd](./implant-anneal-excerpt.cmd)
  - BF₂ LDD implantation
  - Nitride spacer deposition / etch
  - BF₂ Source/Drain implantation
  - 1000 °C anneal command

## Not Included

전체 mesh, geometry initialization, oxidation, polysilicon, metallization, reflect, contact 관련 원본 command는 완전한 실행 파일 형태로 보존되어 있지 않습니다.

따라서 이 폴더의 command는 **보고서 기반 핵심 발췌본**이며 standalone simulation deck이 아닙니다.
