# SVisual Source Scope

원본 SVisual extraction script 전체는 현재 저장소에 포함되어 있지 않습니다.

보고서에서 사용한 주요 결과 지표는 다음과 같습니다.

- Vtgm
- drain current
- leakage current
- subthreshold swing (SS)
- drive/leakage current ratio

PMOS drain current는 부호가 음수이므로 저장소의 비교 표에서는 전류 크기(abs)를 별도로 기록했습니다.

원본 extraction Tcl code가 확보되지 않은 상태에서 임의의 자동 추출 script를 만들어 넣지 않았습니다.
